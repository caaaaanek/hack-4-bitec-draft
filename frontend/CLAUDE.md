# Integrity Assessment Platform: frontend

Фронтенд платформи оцінювання доброчесності для ВВНЗ. Працюємо лише всередині `frontend/`. Лише синтетичні дані.
Поки не підключений до бекенду (`../backend`): дані з `src/demo`.

## Стек

Vite, React 19, TypeScript strict, Tailwind 4, React Router, TanStack Query, Recharts, MSW (моки),
Vitest, Playwright (devDependency, перевірка екранів), eslint, prettier. Шрифт Onest (`@fontsource-variable/onest`,
лише cyrillic і latin). Іконки `lucide-react`. Alias `@/` це `src/`. `<html lang="uk">`.

## Команди

- `npm run dev`, `npm run build`, `npm run typecheck`, `npm run lint`, `npm run test`
- `npm run check:contrast`: контраст пар токенів (4.5:1 текст, 3:1 великі елементи)
- `npm run verify`: усі перевірки етапу (typecheck, lint, test, build, contrast, екрани)
- Перед завершенням етапу запускай `npm run verify`. Усе має бути зеленим.

## Структура

Не перечитуй увесь `src`. Структуру, токени й компоненти дивись у `docs/DESIGN_SYSTEM.md`.

## Принципи

Один екран, повне розуміння. Кожне число пояснюється й веде до розкладу. Розвиток, а не покарання:
жодних рейтингів чи ліг людей і підрозділів. Довіра видна поруч з індексом. Колір ніколи не єдиний
носій значення (цифра, іконка, візерунок, форма). Анонімність видно в інтерфейсі. Закритий контур:
жодних зовнішніх запитів (CDN, шрифти, іконки, аналітика, карти). Одна термінологія. Стриманий вигляд.

## Заборонено в UI-текстах

Довге тире (U+2014), слово «підприємство», слова-ярлики на людях, слово «рейтинг» щодо підрозділів чи
людей. Звертання на «ви». Мова: українська.
