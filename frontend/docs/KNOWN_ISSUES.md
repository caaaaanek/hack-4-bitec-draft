# Відомі обмеження

- Бриф `docs/DESIGN_BRIEF.md` тепер у репозиторії; звірку див. у розділі «Відповідність брифу» в `docs/DESIGN_SYSTEM.md`.
- Стани hover, active на сторінці `/design` не зафіксовані статично: їх видно лише при взаємодії.
- Playwright-перевірка запускається лише в Chromium; Firefox і WebKit не перевірялися.
- Візерунки зрілості для друку перевірено лише за CSS (print.css), фізичний друк не тестувався.
- Шрифт Onest підключено через власний `fonts.css` (лише cyrillic і latin), бо пакет не має окремих CSS по піднаборах.
- Дашборд не показує окремих фактів, тому кількості фактів («45 з 100 (45%)») видно лише на `/explain` у режимі «Факти».
- Кнопка «Переглянути результати підрозділу» на екрані подяки в демо перемикає роль на респондента, бо опитування відкривається за посиланням без входу.
- Заглушки `/manage`, `/surveys`, `/checklist`, `/audit`, `/reports` лише пояснюють майбутній вміст.
- Матриця перевірки не проходить анкету з клавіатури (Tab, стрілки): це покрито лише тестами компонентів і ручною перевіркою.
- Дві теми: світла основна, темна за перемикачем. Скріншоти `verify`: світла на 360, 768, 1280, 1920; темна лише на 1280 для `/`, `/trends`, `/recommendations`. Інші екрани в темній темі перевірені контрастом токенів.
- Кнопка «Експорт» не додана: екран звітів лишається заглушкою. Селектор періоду є на картці динаміки й на `/trends`. Теплокарти й ComparisonBars у проєкті немає, тож тематизовано gauge, радар, лінію динаміки, кроки зрілості.
- Кнопка сповіщень показує, що нових сповіщень немає (синтетичні дані без подій). Іконка довідки веде на `/explain` і прихована для ролей без доступу туди.
- Підписи й заголовки карток 12 px за вказівкою щодо щільності (раніше мінімум 14 px).
- Друк світлий завдяки дублю світлих токенів у `@media print`; фізичний друк не тестувався.
- Порядок третього ряду дашборда: «Компоненти», «Що потребує уваги», «Радар» (а не «Компоненти», «Радар», «Увага»), щоб порядок Tab, візуальний і мобільний порядок збігалися без `tabindex`.
- Заклади Бета, Гамма, Омега генеруються детерміновано (seed), значення питань округлені до 5 пунктів, щоб розклад сходився точно.
- Рекомендація про розбір закупівель спирається на розбіжність сприйняття й фактів у Підзвітності; даних закупівель ще немає (інтеграція планується, див. `/integrations`).
- Дата «сьогодні» для заходів зафіксована в демо (`TODAY` у `src/demo/measures.ts`), щоб «Прострочено» було відтворюваним.
- Лічильники в навігації рахуються лише за закладом Альфа.
- Дашборд на 1280x720 потребує невеликої прокрутки (близько 140 px).
