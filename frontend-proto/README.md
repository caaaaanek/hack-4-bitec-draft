# frontend-proto

Альтернативний фронтенд Integrity Dashboard: одна сторінка без збірки (HTML + vanilla JS), власний дизайн. Методика, дані й тексти — як у `frontend/` (Integrity Index, 8 ролей, 5 правил рекомендацій), заглушки `frontend/` тут робочі: звіт, керування циклом, анкети, чек-лист «чотири ока», журнал з ланцюгом хешів, порівняння.

Демо: https://integrity-prototype.vercel.app

## Запуск

З бекендом (основний режим): `docker compose up --build` у корені репозиторію → http://localhost:8080, вхід демо-логінами
(див. `docs/run.md`). Режим визначається автоматично: відповідає `GET /api/v1/config` — дані й вхід з бекенду (`src/0-api.js`).

Без бекенду:

```bash
xdg-open index.html             # усе працює з файлу, асистент — на шаблонах правил
./start.sh                      # сайт + асистент на локальній моделі Ollama (gemma3:4b) → http://127.0.0.1:3000
```

## Структура

- `src/` — частини коду; після правок `python3 src/build.py` збирає їх у `index.html`.
- `api/assistant.js` — серверна функція асистента (будь-який OpenAI-сумісний `/chat/completions`, ключ лише в змінних оточення).
- `server.mjs`, `start.sh` — локальний сервер для закритого контуру.

ШІ лише пояснює вже розраховані правилами числа й пише чернетки; вимикається перемикачем, без нього все працює.
